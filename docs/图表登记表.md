## 图件规范自检

- 图题位于图下方，表题位于表上方 ✓
- 正文先提及图，再放图 ✓
- 图中术语与正文一致（n_H/n_L/n_s、λtarget、TMM、MLP）✓
- 结构性图保留可编辑源文件（matplotlib 脚本）✓
- 表格采用三线表 ✓
- 图内字号在论文缩放后约 6.5–8 pt，满足印刷可读要求 ✓
- 全部图件由 `src/make_all_figures.py` 一键重建，数据可溯源到 `results/` ✓
- 公式为原生 Word 公式，正文引用为 Word 交叉引用域（REF + 书签）✓
- 参考文献表由 Zotero 书目经 citeproc-js 渲染，格式见 `docs/文献核验清单.md` ✓
