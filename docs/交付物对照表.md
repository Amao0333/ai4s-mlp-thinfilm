## 五、额外增加的分析（超出必做要求）

| 内容 | 位置 | 作用 |
|---|---|---|
| 双 TMM 实现互检 + 解析校核 + 在线 TMM 交叉验证 | `src/validate_tmm.py`、`src/dreapex_crosscheck.py` | 证明物理内核正确（差异 < 1e−15） |

| 厚度公差敏感性 | `src/tolerance.py` | 工程落地评估 |
| 耗时基准与盈亏平衡规模 | `src/benchmark.py` | 诚实界定代理模型的价值边界 |
| 物理上限的网格穷举确认 | `src/bound_gridsearch.py` | 2.83×10⁶ 点独立确认上限（与解析差 8×10⁻⁶） |
