# 文献核验清单

参考文献不使用手工录入：全部条目由脚本从**权威接口**抓取，元数据存放于
`results/references_authoritative.json`（唯一数据源），再依次生成
`references.bib` / `references.ris`（导入 Zotero 等文献管理器）、
`results/references_csl.json`（CSL-JSON）与 `results/references_gbt7714.json`（文献表）。

- 抓取脚本：`src/fetch_references.py`
- 导出脚本：`src/export_references.py`、`src/make_csl_json.py`
- 渲染脚本：`tools/render_bibliography.mjs`（citeproc-js + GB/T 7714-2015 样式）
- 文献管理：Zotero（条目已入库，可导入 `references.ris` 复现同一书目）

## 核验过程中的两处修正

1. **[8] 作者名**：早期稿件写成「Meng F, Ding J, Zhao Y, et al.」，与 DOI 记录不符。
   Crossref 权威记录（10.3390/photonics11100964）显示该文仅两位作者：
   **Su Kalayar Swe** 与 **Heeso Noh**。已按权威记录更正，并在
   `src/check_consistency.py` 中增加了作者姓氏比对与第 [8] 篇专项回归检查。
2. **[1] 年份与版次**：早期稿件写 2018。出版社与 Crossref 记录（10.1201/b21960）均为
   **2017-12-15**，第 5 版，已更正为 2017。

## 关于引用编号

正文引用采用 **GB/T 7714-2015 顺序编码制**：文献编号按正文首次引用先后连续排列。
早期稿件的编号顺序与正文首次引用顺序不一致，已重排为 [1]→[12] 严格对应首次出现位置，
并由 `check_consistency.py` 检查「文献表条目均在正文被引用」与「编号 1..N 连续」。

## 管理方式

- `references.ris` / `references.bib` 可直接导入 Zotero、EndNote、NoteExpress。
- Zotero 书库已建立（12 条），条目元数据与上表一致。
- 论文文献表由 `tools/render_bibliography.mjs` 渲染：引擎为 citeproc-js（Zotero 内部同款），
  样式取自 Zotero 样式仓库的
  `china-national-standard-gb-t-7714-2015-numeric`（样式文件已随仓库提供于 `tools/`）。
- 双语处理：中文条目按国标用「等」，西文条目用「et al.」；西文图书版次写 `5th ed.`。
